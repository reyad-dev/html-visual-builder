# 15 — Future Roadmap

Nothing in this file is part of MVP unless promoted into Product Spec and Acceptance Criteria.

## V1.1 — Better source handling
- controlled external stylesheet loading;
- base URL handling;
- ZIP import with local assets;
- CSS code view;
- advanced class/selector management;
- multi-page project UI.

## V1.2 — Asset system
- local asset library;
- optimized image upload;
- cloud object storage;
- replace image across project;
- asset metadata.

## V1.3 — Component system
- reusable symbols/components;
- saved user blocks;
- template library;
- global design tokens;
- CSS variables UI.

## V1.4 — Advanced responsive editing
- breakpoint authoring;
- per-device style indicators;
- responsive value inheritance UI.

## V2 — Cloud projects
- backend API;
- authentication;
- database;
- project version snapshots;
- cloud storage;
- share links.

## V2.x — Collaboration
- comments;
- presence;
- conflict-safe collaborative editing.

## Optional AI track
Only after editor correctness:
- natural-language style changes;
- generate sections;
- explain selected CSS;
- accessibility suggestions;
- copy rewriting.

AI must call controlled editor commands, not write arbitrary DOM directly.

## Potential CMS integrations
- WordPress export/import helper;
- reusable Gutenberg-safe output mode;
- CMS template APIs.

These need separate specifications because CMS sanitization and markup rules differ.
